# Bangumi 作品年份分布

查看看过的动画、在玩的游戏、读过的书籍等收藏的发行年份分布。

在 [Bangumi 组件页](https://bgm.tv/dev/app/7056)启用后，打开个人页或收藏页即可使用。

## 查看收藏

选择类别，再选择「看过」「在看」等收藏状态。「概览」汇总该类别的全部收藏状态。进入收藏列表页时，组件自动选中页面对应的类别和状态。

- **年代柱状图**：按十年汇总，适合查看跨度较大的收藏；点击年代柱即可展开查看各年。
- **年度柱状图**：在连续年份轴上比较各年的数量。
- **年度条形图**：每年一行，直接查看数量与占比。

柱状图支持鼠标悬停查看，以及前后按钮和键盘左右键逐项查看。点击年代柱展开各年，点击年份柱选定该年。浏览器会记住所选图表类型。

## 数据口径

年份取自作品的首播、上映、出版、发行、发售或连载开始日期。登录后查看自己的收藏时，统计包含自己可见的作品。

占比以当前类别、状态的收藏总数为分母，展开某个年代时也使用这一总数。年份待确认的作品计入总数，可展开查看作品链接。

结果在浏览器缓存六小时，过期后自动更新。收藏变化时更新受影响的状态，也可点击组件底部的「刷新」主动更新。后台更新失败时保留上次结果。

## 开发

```bash
npm ci
npm run check
```

构建产物为 `dist/gadget.js` 和 `dist/gadget.css`，分别填入 Bangumi 开发版本的脚本和样式字段。
