# Bangumi 收藏作品年代

在个人页与收藏页查看作品的年份分布。支持动画、书籍、音乐、游戏、三次元；各类别使用 Bangumi 对应的收藏状态名称。

## 使用

在[组件页](https://bgm.tv/dev/app/7056)启用后，打开个人页或收藏页即可查看统计。

- 个人页：右侧热力图下方显示，默认显示动画概览，选择具体类别后可选择该类别的收藏状态。
- 收藏状态页：默认显示当前类别、当前状态。例如游戏「在玩」页展示在玩游戏的年份分布。
- 收藏概览页：展示当前类别的概览，可切换该类别的状态。
- 手机网页：在内容区顶部以单列显示。
- 每个年份显示作品数量与占所选收藏总数的比例。年份待确认的作品可展开查看条目链接。

## 图表

图表选择器提供三种展示方式，浏览器会记住所选方式：

- 年代柱状图：默认方式，按十年汇总，点击年代柱展开逐年分布，点选年份柱查看数量与占比。
- 年度柱状图：完整年份轴，鼠标点选、滑动条和前后按钮可查看具体年份。
- 年度条形图：每年一行，直接显示数量与占比。

两种柱状图绘图区高度为196px。三种图表使用当前类别与状态的同一份数据，图表切换在本地完成。展开年代后的百分比仍以所选收藏总数为分母。

## 日期与缓存

年份取自作品首播、上映、出版、发行、发售或连载开始日期。列表日期缺失时，同源读取作品详情页的日期字段。登录用户查看自己时，同源请求会包含自己可见的收藏。

结果保存在浏览器本地，按登录账号、目标用户、类别和状态隔离。六小时内直接使用缓存，过期时先显示缓存并在后台更新。页面收藏数量、列表条目或收藏信息变化会使相应类别的缓存失效；顶部「刷新」可主动更新所选范围。读取失败时可重试，后台更新失败时保留上次结果。

## 构建与验证

```bash
npm install
npm run check
```

- `src/core.js`：日期解析、同源分页和分布聚合。
- `src/charts.js`：图表切换、年代汇总、逐年交互和展示偏好。
- `src/cache.js`：缓存隔离、有效期及失效处理。
- `src/app.js`：页面挂载、筛选和自动加载。
- `dist/gadget.js`、`dist/gadget.css`：Bangumi 开发版本的脚本和样式。
