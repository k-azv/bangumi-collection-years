# 页面验证

用于验证组件与 Bangumi 页面、登录权限及浏览器交互的配合。发布开发版本前，先运行 `npm run check`，再在已启用组件的浏览器中完成以下检查。

## 筛选与统计

| 操作 | 核对内容 |
| --- | --- |
| 打开个人页，选择类别和状态 | 状态名称对应类别；总数对应所选收藏 |
| 直接打开收藏状态页 | 默认类别和状态与页面一致 |
| 切换图表类型 | 收藏总数和各年数量一致；网络面板中的收藏数据请求数保持不变 |
| 点击年代柱展开 | 展示完整十年；各年数量之和等于年代数量；占比分母仍为所选收藏总数 |
| 展开年份待确认列表 | 每条作品链接可访问，日期分类与作品资料相符 |

使用自己的收藏核对私有条目。需要复现日期边界时，以 `tests/core.test.js` 的输入样例为准，避免依赖持续变化的作品资料。

## 图表交互

- 鼠标悬停显示对应年份或年代，移出后恢复选定项。
- 点击柱子、前后按钮及键盘左右键，核对高亮与详情一致。
- 展开年代后返回，核对年代选择保留。
- 刷新取得相同数据、切换浏览器标签页再返回，核对展开位置和年份选择保留。
- 切换图表类型后重新打开页面，核对图表偏好恢复。

## 加载与刷新

使用浏览器网络面板观察请求；慢速网络便于检查加载中的行为。

- 加载过程中切回标签页，当前查询继续完成。
- 缓存有效时再次打开页面，直接显示统计。
- 通过站点修改测试收藏，核对相关状态及概览更新。
- 在另一页面更新收藏后返回，核对页面显示与缓存同步情况。
- 模拟请求失败，核对重试可用，已取得的完整结果仍可查看。

## 布局

分别检查桌面侧栏、窄屏和深色主题：筛选文字、图表详情与操作按钮可见，组件适配容器宽度。窄屏同时检查触摸选柱、前后切换和页面滚动。

发现问题时记录复现步骤、预期与实际结果。附上相关截图或错误信息；仅在定位需要时补充构建版本、浏览器版本、视口和登录状态。
