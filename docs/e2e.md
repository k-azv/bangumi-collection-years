## 类别与状态

[个人页](https://bgm.tv/user/kazv)默认选择动画，显示391部作品。类别选择包含动画、书籍、音乐、游戏、三次元。统计范围始终属于一个具体类别。

| 类别 | 状态选项 |
|---|---|
| 动画 | 概览、想看、看过、在看、搁置、抛弃 |
| 书籍 | 概览、想读、读过、在读、搁置、抛弃 |
| 音乐 | 概览、想听、听过、在听、搁置、抛弃 |
| 游戏 | 概览、想玩、玩过、在玩、搁置、抛弃 |
| 三次元 | 概览、想看、看过、在看、搁置、抛弃 |

实测书籍“读过”为17部；切换到游戏时选择器回到“概览”，显示20部；选择“在玩”为2部，2016年、2022年各1部、各占50%。音乐使用想听、听过、在听等状态名称。
