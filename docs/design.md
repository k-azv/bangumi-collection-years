# 维护说明

## 模块职责

| 文件 | 职责 |
| --- | --- |
| `src/core.js` | 页面路径识别、收藏分页读取、日期解析、年份聚合 |
| `src/cache.js` | 缓存隔离、持久存储、内存回退、有效期与失效处理 |
| `src/charts.js` | 年代汇总、年份选择、图表偏好与尺寸适配 |
| `src/app.js` | 页面挂载、筛选、请求调度与结果展示 |
| `src/style.css` | 组件样式与深色、窄屏适配 |

## 数据读取

收藏页通过同源请求携带当前登录会话，返回范围由站点权限决定。每个状态读取全部分页，收藏分页和日期详情共用最多四个并发请求。结果按类别和作品 ID 去重。

收藏条目来自 `#browserItemList > li`，作品日期取自 `p.info.tip`。`.collectInfo` 用于识别收藏可见性。列表资料缺少年份时，读取作品详情的 `#infobox`，单个状态最多调度两个详情页；请求在十五秒后超时。

详情页的日期字段因类别而异，由 `RELEASE_FIELDS` 定义。多个匹配字段提供日期时取最早年份；`*`、未定、TBA 等值标记为待定，其余未识别日期标记为待补充。修改日期规则时，应同时补充 `tests/core.test.js` 中对应的输入样例。

## 请求与缓存

缓存按登录身份、收藏用户、类别和状态隔离。每份数据有效六小时；过期的完整结果先展示，再更新过期部分。查询范围尚未完整取得时显示加载状态。

相同查询正在加载时复用请求。切换查询会中止上一组请求，并用请求序号避免旧结果覆盖当前结果。列表变更延迟 500 毫秒处理，以合并连续 DOM 更新。

页面收藏计数相对记录值发生变化，或条目日期、可见性变化时，使受影响状态的缓存失效。页面计数与可见条目数分别记录。恢复页面可见或从浏览历史恢复时复核数据。

重复读取复用已解析的数据；持久缓存内容变化时重新解析。存储写入失败时使用页面内存缓存。持久缓存最多保留 50 条记录，写入时清理超过七天的记录。

展示层比较各状态的数据引用，内容相同的刷新结果保留引用，使图表继续保持选中年份和展开位置。修改缓存时应验证跨页面更新、删除及存储异常，避免旧结果持续显示。

## 页面适配

个人页挂载到 `#columnB` 的热力图下方，兼容热力图异步插入。收藏页使用 `#columnSubjectBrowserB` 或 `#columnB`；窄屏使用主内容区顶部。站点结构变化时，优先检查 `mountRoot` 与 `parseRoute`。

年份图的节点数随年份跨度增长，绘图区宽度跟随容器调整。替换图表时释放对应的尺寸观察器。修改交互时，应验证悬停预览、选定恢复、年代展开、键盘操作与数据刷新后的状态保留。
