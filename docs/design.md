# 收藏作品年代产品设计

## 信息架构

- 用户主页：汇总动画、书籍、音乐、游戏、三次元，支持按媒介切换。
- 收藏页：展示当前媒介的五种收藏状态年度分布。
- 年份口径：作品发行年份。动画与三次元取首播或上映年，游戏取发售年，书籍取出版年，音乐取发行年；站点资料缺少年份的作品单列为“年份未知”。

## 交互

组件初始只显示说明与“加载收藏统计”，由用户主动开始读取分页。加载过程显示完成的收藏分类数与页数。统计完成后，状态图例可单独开关，至少保留一种状态。收藏时间不参与任何统计。

## 视觉

颜色沿用 Bangumi 的粉色主色与低饱和蓝、绿、黄、灰状态色。结构采用站内常见的细灰边框、五像素圆角、小字号和紧凑间距。年度条形图是唯一强调元素，其余控件保持站内信息密度。

桌面布局：

```text
┌ 收藏作品年代  按作品发行年份统计，包含私有收藏 ┐
│ [全部] [动画] [书籍] [音乐] [游戏] [三次元] │
│ 447 部有发行年份 · 共 452 部                │
│ ●想看  ●完成  ●进行中  ●搁置  ●抛弃       │
│ 2026  ███████████████████████  38          │
│ 2025  █████████████████████████████  52    │
└─────────────────────────────────────────────┘
```

移动布局保留相同信息顺序，媒介标签横向滚动，图表宽度自适应单列容器。
